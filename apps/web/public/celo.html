🎲Ludo Arena

Get on Celo in 2 minutes

Ludo Arena runs on the Celo blockchain — fast, with cents-level fees (which the platform pays for you). The game plays in your mobile browser, no app to install.

1Add the Celo network to MetaMask

  1. Open MetaMask → tap the network selector (top left)
  2. Add network → Add a network manually
  3. Fill in exactly:
Network nameCelo Mainnet
RPC URLhttps://rpc.ankr.com/celo
Chain ID42220
Currency symbolCELO
Block explorerhttps://celoscan.io

Save, then switch to Celo Mainnet.

2Open the game and connect

  1. Open ludoarena.xyz in the MetaMask in-app browser (Menu → Browser) — smoothest on mobile. Chrome + the MetaMask app works too.
  2. Tap Connect Wallet and approve the signature.

⚠️ “Insufficient funds” with a funded wallet?

Your Celo network entry is using a rate-limited RPC. Edit the network in MetaMask and set the RPC URL to https://rpc.ankr.com/celo.

💡 MiniPay users: the game isn’t listed in MiniPay’s Discover tab yet — open ludoarena.xyz in your normal mobile browser for now.
